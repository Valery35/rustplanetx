## RU - Telegram, ВК, Facebook

RustPlanetX 0.6.2 - трёхмерный глобус PlanetX для RustGIS 0.7.0.

Для Windows, Linux и macOS теперь у каждой системы свой пакет, и каждый меньше 23 МБ. Расширению нужен RustGIS 0.7.0 или новее, глобус связывается с картой сразу, без дополнительных настроек. Заявка в каталог расширений RustGIS с пакетами по системам ждёт проверки сопровождающих каталога.

Установка - «Plugins › Plugin Manager › Settings › Install From File…» с пакетом своей системы со страницы выпуска.

Выпуск - https://github.com/Valery35/rustplanetx/releases/tag/v0.6.2

## EN - LinkedIn

RustPlanetX 0.6.2 - the PlanetX 3D globe for RustGIS 0.7.0.

Windows, Linux and macOS now each have a package of their own, each under 23 MB. The plugin needs RustGIS 0.7.0 or newer, and the globe links with the map at once, with no extra settings. The registry pull request with a package per system waits for the review of the registry maintainers.

Install from Plugins › Plugin Manager › Settings › Install From File… with the package of your system from the release page.

Release - https://github.com/Valery35/rustplanetx/releases/tag/v0.6.2
